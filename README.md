# 未完待续 · 个人博客第一版

参考博客的全屏封面、透明导航、文章卡片布局，搭建了一个独立的静态博客。当前站名、个人介绍、六篇文章和配图均为示例。

## 本地运行

需要 Node.js 22 或更新版本（建议使用 Node.js 24 LTS）。

```sh
npm ci
npm run build
npm run dev
```

在浏览器打开 `http://127.0.0.1:4173`。修改文件后，重新执行 `npm run build` 并刷新浏览器。服务器读取 `dist/`，不提供热更新。

## 换成自己的内容

- `site.config.mjs`：站名、首页标题、描述、个人介绍、站点网址。GitHub 和邮箱默认留空，填写后会在关于页显示。
- `content/posts/*.md`：用 Markdown 写文章。复制一篇文件，修改文件名、元数据和正文即可。文件名决定文章链接。
- `public/assets/`：封面、头像装饰、插图和图标。可用自己的图片替换同名文件。
- `public/style.css`：配色、字体和布局。
- `public/app.js`：搜索、分类和标签筛选、深浅色模式、手机导航、复制链接。

文章开头的元数据：

```yaml
---
title: 我的第一篇文章
date: 2026-10-18
category: 日常随笔
tags: 生活, 随想
cover: /assets/hero.jpg
summary: 文章摘要。
featured: true
---
```

分类从「日常随笔、技术手记、沿途风景」选择；需要新分类时，同步修改配置的 `categories`，并按需扩展生成脚本里的图标映射。`featured: true` 显示置顶角标，文章列表目前按日期倒序排列。

`demo: true` 会禁止搜索引擎索引示例站。替换真实内容后可设为 `false`，同时调整生成脚本中的示例提示文案。绑定独立域名后，更新 `origin` 再构建，让 RSS、站点地图和分享图片使用新地址。

## 页面与发布

包含首页、六篇文章详情、分类与标签、时间归档、关于页、404、RSS 和站点地图。文章详情是独立 HTML 页面，可直接访问、刷新或分享。

首页保留站名和山谷封面，并按文章日期展示最近 4 篇笔记。每 6 秒自动横向切换一页，最后一页继续循环到首页；也可以左右滑动，使用分页圆点、切换按钮或左右方向键手动翻页，手动切换后会重新计时。滚动离开首屏、浏览器标签页隐藏或正在操作笔记链接时暂停自动播放；系统开启减少动画时使用手动翻页。点击「开始阅读」可向下滚动到「最近的记录」。

`npm run build` 生成 `dist/`。页面仍是静态输出，可部署到支持静态网站的平台；评论和浏览量由独立的 Waline 服务提供。博客目前托管于 Cloudflare；`.openai/hosting.json` 保留了最初创建时的 Sites 标识。本次接入仅修改本地项目，没有推送 GitHub 或触发 Cloudflare 部署。

## 评论与浏览量

已接入 Waline，服务端部署在 Netlify，数据存储在 Neon。前端只包含公开的服务地址，不包含数据库密码或管理员凭据。

- 配置入口：`site.config.mjs` 中的 `waline.serverURL` 和 `waline.pageview`。将 `pageview` 设为 `false` 可关闭浏览量，将 `serverURL` 留空可关闭整个评论与计数入口。修改后重新构建。
- 每篇文章末尾显示评论区，无需注册、登录或邮箱。首次访问自动生成随机昵称，访客可以直接使用，也可以修改；清空昵称仍会使用自动昵称。昵称会尽量保存在当前浏览器中，方便继续交流，它不是账户或唯一身份标识。邮箱、网址和登录入口均不显示。评论区跟随网站深浅色模式，在接近可视区域时加载。
- 为避免隐藏字段继续带上旧资料，加载评论前会清空当前博客域名下 Waline 缓存的邮箱、网址和前端登录状态，保留已填写的昵称。Netlify 域名下的管理后台账户与登录不受影响。
- 首页卡片、归档和标签页只查询浏览量；访问文章页时增加一次浏览量。这里统计的是页面访问次数（PV），不是独立访客（UV），刷新文章会再次计数。
- 在 `localhost`、`127.0.0.1`、`::1` 或 `.localhost` 域名预览时，只查询浏览量。评论仍连接线上数据库，提交的留言会真实保存。
- 评论和浏览量都以 `/posts/文章文件名/` 为标识。查询参数、锚点、`index.html` 访问方式和域名变化不会分割同一篇文章的数据。文章上线后尽量保持 Markdown 文件名不变；改文件名等于更换数据标识，需要单独迁移旧数据。
- `@waline/client` 固定版本随 npm 锁文件安装。构建时复制客户端资源到 `dist/vendor/waline/`，不依赖外部 CDN。`public/community.js` 负责加载和计数，`public/community.css` 负责样式。
- 管理后台：<https://review-setting.netlify.app/.netlify/functions/comment/ui>。当前管理员账户继续使用；网站更换域名不需要重新注册。

当前 `origin` 已填写 Cloudflare 临时域名。后续绑定正式域名时更新它并重新构建；如果在 Netlify 配置了 `SITE_URL` 或 `SECURE_DOMAINS`，也应同步调整。继续使用同一 Waline 服务和 Neon 数据库即可保留账户与数据。
