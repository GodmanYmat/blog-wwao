## 为什么还想拥有一个博客

社交平台适合分享正在发生的事，而博客适合保存想要留下的东西。一段解决问题的过程，一页读书笔记，或一个还没来得及想清楚的念头，都可以在这里找到位置。

这个地方不需要很大。清楚的导航、舒服的字体，以及一篇愿意认真写完的文章，就足够成为起点。

## 从最小的一步开始

先写下标题，再写三句正文。不要急着调整所有样式，也不用等到拥有完整的内容计划。一个小小的完成，比一个无限延后的完美开头更有用。

```js
const garden = {
  thoughts: [],
  grow(idea) {
    this.thoughts.push(idea);
  }
};

garden.grow('今天，先写一点。');
```

## 让内容拥有自己的节奏

可以写技术，也可以写生活。不必把每一篇都变成教程；那些走过的弯路、没有解决的问题，同样值得记录。

> 数字花园的意义，也许不在于长成什么样子，而在于持续照料它。

以后回看时，我们会发现，零散的记录已经悄悄连成了一条路。
